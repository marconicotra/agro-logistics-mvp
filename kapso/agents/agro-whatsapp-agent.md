# Legacy Kapso Agent (Inactive)

AGRO conversations are owned by the backend and use the backend's OpenAI
configuration. This prompt is intentionally retired and must not be attached to
an active Kapso workflow; doing so would reintroduce duplicate replies and
Kapso AI credit usage.

The `agro-whatsapp` workflow source is kept in draft. The signed inbound webhook
and Kapso outbound adapter carry WhatsApp messages.
